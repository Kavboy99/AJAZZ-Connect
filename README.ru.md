# AJAZZ Connect 0.2.0 (рабочее название)

[English version](README.md)

Название рабочее и будет заменено. Проект движется к универсальному приложению для настройки
и кастомизации PC-устройств любых производителей (клавиатуры, мыши, подсветка, вентиляторы
и т. д.); сегодняшняя версия — первый срез для клавиатур. Направление и правила:
`AGENTS.md`, `docs/ARCHITECTURE.md`.

Windows x64: штатная настройка цвета разных клавиатур, диагностика USB и статический
анализ прошивочных EXE/BIN. Установка, Python и права администратора готовому EXE не нужны.

Программа не ограничивает настройки одной прошивкой 1.36, магнитными переключателями
или названием Max Ultra. Протокол выбирается по интерфейсам и проверяется обменом.
Проект ведётся на двух клавиатурах одной модели, но разных платформ: магнитной AK820 MAX
Ultra (SONiX, у соавтора) и механической AK820 MAX `GPWB2401` (BY Tech `258A:010C`, у
владельца репозитория). Управление цветом сейчас работает только для SONiX-ветки; механическая
распознаётся диагностикой, но адаптера для неё ещё нет. Подробности: `docs/DEVICES.md`.
Правила разработки: `AGENTS.md`.

## Способы управления

| Адаптер | Критерии допуска | Действие | Восстановление |
| --- | --- | --- | --- |
| AJAZZ AA55 | SONiX AK820, FF68:0061, Input/Output 65 с Windows Report ID, точный GET_INFO с совпавшим VID/PID, известный формат LED_EFFECT | Штатный постоянный цвет, сохраняемая настройка; обратное чтение | Исходный блок LED_EFFECT сохраняется до первой записи; кнопка или JSON |
| SONiX Feature, экспериментальный | 0C45:8009/800A, AK820/AK820 MAX, FF13:0001 Feature 65, FF68 Output 4097 того же USB-контейнера, точный START ACK | Постоянный цвет, сохраняемая настройка; проверка ACK | Исходный эффект не читается; автоматический откат недоступен, режим можно выбрать Fn на клавиатуре |
| HID LampArray | Любой VID/PID, стандартная клавиатура 0059:0001; проверяются поля, порядок, ширины и ID отчётов | Цвет программируемых ламп без замены прошивки | Автономный режим кнопкой или при штатном закрытии |
| OpenRGB SDK | Локальный SDK Server; клавиатура уже поддерживается самим OpenRGB; Direct без флага Automatic Save | Постоянный цвет через существующий драйвер OpenRGB | Состояние сервера сохраняется до первой записи; кнопка или JSON |

Физическая проверка новых адаптеров не зафиксирована ни на одной из двух клавиатур
(`docs/DEVICES.md`, журнал); на механической GPWB2401 ни один адаптер не применим. Тесты проверяют кодеки,
эталонный HID-дескриптор Microsoft, опубликованные пакеты SONiX и работу SDK с отдельным
тестовым TCP-сервером. Проверка ACK/состояния сервера не заменяет наблюдение цвета на клавиатуре.
Ни один адаптер не реализует переход в загрузчик, стирание или загрузку прошивки.

## Запуск

1. Распаковать `AJAZZ-Connect-0.2.0.zip`, запустить `AJAZZ-Connect.exe`.
2. Для AJAZZ подключить кабель, выбрать USB, закрыть другие программы настройки.
3. На вкладке «Подсветка» выбрать адаптер и нажать «Найти клавиатуры».
4. Выбрать клавиатуру, цвет и нажать «Применить цвет».
5. Для OpenRGB сначала включить SDK Server на порту 6742. Его сервер здесь не запускается
   и список поддерживаемых им устройств не расширяется одним подключением к SDK.

Резервные копии AA55/OpenRGB: `%LOCALAPPDATA%\AjazzConnect\backups`. Возврат из файла
проверяет принадлежность устройству и формат. В SONiX Feature отсутствует команда чтения
исходного эффекта; приложение заранее показывает это ограничение.
Не запускайте одновременно несколько программ, управляющих одной клавиатурой.

## GPWB2401 и прошивки

Вкладка «Диагностика и прошивка» сохраняет JSON с USB-интерфейсами, семействами протоколов
и доступным GET_INFO. Выбор EXE/BIN извлекает активный образ и метаданные без запуска EXE.
ZIP/RAR или неизвестный формат нельзя переименовывать в BIN. Для механической GPWB2401
(по USB это `258A:010C`, BY Tech) прошивка недоступна: контроллер, карта памяти и
подходящий образ не установлены.
Название архива AK820MAX не доказывает ни тип переключателей, ни универсальность образа.

Подробный разбор: `docs/KEYBOARD-FAMILIES-RE.md`, исходный разбор прошиватора:
`docs/ORIGINAL-UPDATER-RE.md`. Локальные копии источников и их хэши перечислены в
`research/SOURCE-MANIFEST.json`.

В локально извлечённом AK820MAX V1.0 подтверждены BYCOMBO4 и USB 258A:010C,
RF 3554:FA09. Это ветка механической GPWB2401 (проводной ID подтверждён диагностикой
2026-10-28). Её конфиги описаны в research/AK820MAX-V1-BYTECH.json;
команды SONiX к ней не отправляются, нативная запись BY Tech пока не включена.

## Исходники и проверки

Rust 2024. `src/aa55.rs`, `src/sonix_feature.rs`, `src/lamparray.rs` и `src/openrgb.rs`
разделяют транспорты. `src/families.rs` содержит пассивную классификацию, а не разрешения
на запись прошивки. `tools/` содержит автономную модель SONiX ISP и статический анализатор:
они не открывают HID. Часть расширенного анализа требует pefile/capstone/Unicorn/Ghidra;
готовый EXE от них не зависит.

```powershell
cargo test
cargo clippy --all-targets -- -D warnings
cargo build --release
```

`build.ps1` использует локальные GNU-инструменты, если они доступны; иначе обычный Cargo.
CLI выполняет только диагностику и анализ:

```powershell
AJAZZ-Connect.exe --probe report.json
AJAZZ-Connect.exe --inspect vendor.exe inspection.json
AJAZZ-Connect.exe --lighting-probe aa55 aa55.json
AJAZZ-Connect.exe --lighting-probe feature feature.json
AJAZZ-Connect.exe --lighting-probe lamparray lamparray.json
AJAZZ-Connect.exe --lighting-probe openrgb openrgb.json
```

`feature` при проверке открывает/закрывает сеанс START/FINISH; SAVE и изменение цвета
не отправляются. Поля `settings_writes=false` диагностического отчёта относятся к этой
проверке, а не к действиям пользователя кнопкой «Применить цвет».
