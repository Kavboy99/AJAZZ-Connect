# Lusorium Studio 0.3.0

Резервное копирование: отдельная утилита lusorium-backup.exe лежит в папке проекта; те же действия доступны в основной программе. Инструкция: [BACKUP-README.ru.md](BACKUP-README.ru.md). После инцидента запись подсветки BY Tech заблокирована; доступно восстановление проверенного системного блока. Полные дампы произвольных клавиатур не поддерживаются. Старые описания записи подсветки ниже являются историческими.

[English version](README.md)

Lusorium Studio (раньше — «AJAZZ Connect») настраивает конкретные поддерживаемые устройства через собственную проприетарную систему управления и прямые адаптеры протоколов. Сейчас разработка ведётся для аппаратных вариантов AK820 MAX на SONiX и BY Tech. Поддержка проверяется для каждой аппаратной версии; внешний RGB-сервис не требуется. Правила: `AGENTS.md`, `docs/ARCHITECTURE.md`.

Windows x64: однотонная подсветка через драйверы протоколов и пассивная диагностика USB/HID; найденные
устройства показываются квадратными плитками с 3D-моделью. Установка, Python и права администратора не
нужны.

Протокол выбирается по интерфейсам и подтверждается обменом, а не по названию товара. Проект ведётся
на двух клавиатурах одной модели, но разных платформ: магнитной AK820 MAX Ultra (SONiX, у соавтора) и
механической AK820 MAX `GPWB2401` (BY Tech `258A:010C`, у владельца репозитория). Для механической
теперь есть экспериментальный драйвер `by_tech`: протокол восстановлен статическим разбором пакета
производителя, на самой клавиатуре запись ещё не проверена. Подробности: `docs/DEVICES.md`.

## Драйверы

| Драйвер | Допуск | Действие | Откат |
| --- | --- | --- | --- |
| SONiX AA55 | `0C45`, `FF68:0061`, Input/Output 65, совпадение с профилем, точный GET_INFO с тем же VID/PID, известный формат LED_EFFECT | Постоянный цвет; обратное чтение | LED_EFFECT сохраняется в файл до первой записи; кнопка или файл |
| SONiX Feature (экспериментальный, по умолчанию выключен) | `0C45:8009/800A`, точное имя товара, `FF13:0001` Feature 65, `FF68` Output 4097 в том же USB-контейнере, точный START ACK | Постоянный цвет; проверка ACK | Нет: протокол не читает исходный эффект |
| HID LampArray | Любой VID/PID с `0059:0001`; проверяются поля, порядок, ширины и ID отчётов | Цвет программируемых ламп; любой тип LampArray (клавиатура, мышь, ...) | Автономный режим кнопкой или при закрытии |
| BY Tech (экспериментальный, по умолчанию выключен) | `FF00:0001` Feature 520 (Report ID 6), профиль `258A:010C`, точный ответ на запрос пароля `03 00 00 00 01 42` или `…01 5E` (одно- или трёхрежимная плата; только по USB) | Постоянный цвет: статичный эффект в 128-байтном блоке настроек и таблица цветов; обратное чтение обоих | Оба блока сохраняются в файл до первой записи; кнопка или файл |

Физическая проверка драйверов не зафиксирована ни на одной клавиатуре (`docs/DEVICES.md`, журнал).
Тесты проверяют кодеки, порядок обмена на сценарной шине, эталонный HID-дескриптор Microsoft,
опубликованные пакеты SONiX. Ни один драйвер не реализует загрузчик,
стирание или загрузку прошивки.

## Как пользоваться

1. Запустите EXE. Устройства находятся сами: при старте и при каждом подключении или отключении
   (только чтение; об изменении сообщает система, постоянного опроса нет).
2. «Устройства» показывает их плитками; «Обновить» запускает поиск заново.
3. Откройте устройство: на его странице есть раздел для каждой возможности. В «Подсветке» выберите цвет
   и нажмите «Применить цвет». Значки заранее показывают, сохраняется ли цвет и можно ли его откатить.
4. Экспериментальные драйверы включаются в «Настройках».

Резервные копии: `%LOCALAPPDATA%\LusoriumStudio\backups`. Возврат из файла проверяет принадлежность
устройству. Не запускайте одновременно несколько программ, управляющих одним устройством.

## Диагностика

«Диагностика» сохраняет JSON с HID-интерфейсами, их семействами (из `src/profiles/data`),
дескрипторами отчётов и ответами на запросы идентификации. Без серийных номеров, путей устройств и
нажатий клавиш. Приложение для пользователей: анализа прошивок и пакетов в интерфейсе нет. У
разработчиков есть команда `--inspect` (EXE/BIN производителя разбирается как байты и не запускается). Для механической
`GPWB2401` работа с прошивкой невозможна: контроллер, карта памяти и подходящий образ не установлены.

Исследования: `docs/KEYBOARD-FAMILIES-RE.md`, `docs/ORIGINAL-UPDATER-RE.md`. Копии источников и хэши:
`research/SOURCE-MANIFEST.json`.

## Сборка и командная строка

Rust 2024. Структура: `docs/ARCHITECTURE.md`; как добавить устройство или драйвер:
`docs/ADDING-A-DRIVER.md`; правила интерфейса: `docs/DESIGN.md`.

```powershell
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo build --release
```

Все команды только читают устройства; результат — файлы JSON или PNG:

```powershell
lusorium-studio.exe --probe report.json
lusorium-studio.exe --inspect vendor.exe inspection.json
lusorium-studio.exe --lighting-probe sonix_aa55 aa55.json
lusorium-studio.exe --lighting-probe hid_lamparray lamparray.json
lusorium-studio.exe --review review-dir
```

`--lighting-probe` запускает поиск одного драйвера; для `sonix_feature` это включает пару START/FINISH,
но никогда SAVE или цвет. `--review` рисует состояния интерфейса на синтетических данных в PNG (без
устройств, сети и окна).
