# Lusorium Studio 0.3.0

Windows x64. Запустите lusorium-studio.exe. Установка, Python и права администратора не нужны.
Устройства находятся сами при запуске и при подключении; поиск только читает данные.

1. «Устройства» показывает найденное плитками; «Обновить» ищет заново.
2. Откройте устройство, выберите цвет в разделе «Подсветка» и нажмите «Применить цвет».
   Значки заранее показывают, сохраняется ли цвет в памяти устройства и можно ли его откатить.
3. Экспериментальные драйверы (SONiX Feature, BY Tech для механической AK820 MAX по кабелю)
   включаются в «Настройках».
   OpenRGB требует запущенного SDK-сервера на 127.0.0.1:6742.

Резервные копии: %LOCALAPPDATA%\LusoriumStudio\backups (данные прежней папки
AjazzConnect переносятся при первом запуске).

«Диагностика» проверяет подключение и сохраняет отчёт об USB/HID-интерфейсах. Серийные
номера, пути устройств, нажатия клавиш и личные файлы в отчёт не входят. Запись прошивки, стирание и переход в загрузчик не реализованы.
