# AJAZZ Connect 0.2.0

Windows x64. Запустите AJAZZ-Connect.exe. Установка, Python и права администратора не нужны.

Подсветка:

1. Подключите клавиатуру кабелем в режиме USB, закройте другие программы настройки.
2. Выберите адаптер и нажмите «Найти клавиатуры». AA55 — штатный протокол части AK820
   Pro/MAX; SONiX Feature — отдельный экспериментальный протокол старых AK820/MAX/PLUS;
   LampArray — стандарт Dynamic Lighting. OpenRGB требует запущенного SDK Server на 6742
   и устройства, уже поддерживаемого самим OpenRGB.
3. Выберите клавиатуру, цвет и «Применить цвет».

AA55 и OpenRGB сохраняют исходное состояние в %LOCALAPPDATA%\AjazzConnect\backups.
Его можно вернуть кнопкой или из JSON. LampArray возвращает автономное управление
при штатном закрытии приложения. У SONiX Feature исходный эффект не считывается:
автоматического отката нет, режим выбирается сочетанием Fn на клавиатуре.
Настройка AA55/Feature может сохраняться в памяти клавиатуры. Потоковая запись отключена.

На вкладке «Диагностика и прошивка» можно сохранить USB-отчёт и проверить EXE/BIN
прошивки без запуска файла. Имя архива AK820MAX не определяет аппаратную совместимость.
Механическая AK820 MAX (GPWB2401) определяется как BY Tech 258A:010C; управления
подсветкой для неё пока нет, приложение ничего в неё не отправляет. Запись прошивки,
стирание и переход в загрузчик не реализованы.

Если ни один адаптер не подошёл, сохраните диагностический JSON. Серийный номер,
нажатия клавиш и личные файлы в него не входят. Подробный разбор приложен отдельно.
